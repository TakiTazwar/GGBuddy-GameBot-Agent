# ggBuddy

This project is a game analysis assistant implemented in a Jupyter Notebook.

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TakiTazwar/GGBuddy-GameBot-Agent
   cd ggBuddy
   ```

2. **(Optional) Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install the required packages:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
   Then open `ggBuddy.ipynb` in your browser and run the cells.
